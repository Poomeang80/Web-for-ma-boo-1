# Daisy Love Website 🌼

เว็บขอเป็นแฟนแบบ 5 ฉาก ใช้ HTML/CSS/JavaScript เปิดในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไรเพิ่ม

## วิธีเปิด
1. แตกไฟล์ ZIP
2. เปิด `index.html` ด้วย Chrome หรือ Edge
3. ใส่รูปของคุณไว้ในโฟลเดอร์ `Img`
4. เปิด `script.js` แล้วแก้รายชื่อไฟล์ใน `MEMORY_IMAGES` ให้ตรงกับรูปจริง

ตัวอย่าง:
```js
const MEMORY_IMAGES = [
  "Img/เราไปเที่ยว.jpg",
  "Img/วันแรก.png",
  "Img/รูปคู่.jpeg"
];
```
ใช้ชื่อไฟล์และนามสกุลให้ตรงตัวพิมพ์เล็ก/ใหญ่ด้วย

## เพลง
วางไฟล์เสียงที่คุณมีสิทธิ์ใช้งานชื่อ `khor-won-2.mp3` ในโฟลเดอร์ `Img` เพื่อให้เล่นเมื่อกด Yes
เว็บไม่ได้แนบเพลงลิขสิทธิ์มาให้ และเบราว์เซอร์จะพยายามเริ่มเล่นหลังผู้ใช้กดปุ่ม Yes

## ปรับแต่งข้อความ / สี
- ข้อความ 5 ฉาก: แก้ `STORIES` ใน `script.js`
- สีดอกไม้: แก้ `FLOWER_COLORS` ใน `script.js`
- จำนวน/ขนาดดอกไม้: แก้ `makeGarden()` ใน `script.js`
- รูปที่ร่วงลงมาเริ่มตอนเข้าสู่หน้าคำถาม

## หมายเหตุ
เว็บนี้ออกแบบให้เป็นไฟล์ static เปิดในเครื่องได้ ไม่ต้องมี backend หรือฐานข้อมูล
Google Fonts ต้องใช้อินเทอร์เน็ตเพื่อโหลดฟอนต์ หากออฟไลน์จะใช้ฟอนต์สำรองของระบบ
